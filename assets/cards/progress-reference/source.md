# Progress card photograph

Created with the built-in ImageGen tool, using the user's close-up phone-in-hand reference as the edit target. The photograph contains the hands, device and blank display. Dietfit's calendar, weight chart and calorie panel are separate HTML/CSS/SVG, projected onto the display with a responsive perspective transform.

Final web asset: `assets/cards/progress-reference/phone-in-hand.webp` (960 × 1200, 30,736 bytes). The generated PNG was converted to WebP for the website.

## Final prompt

Edit the reference into a photorealistic premium smartphone mockup BACKGROUND ONLY for a website progress-chart card. Preserve the close-up realistic hands holding the silver/graphite modern smartphone, its thin black bezel, black dynamic-island cutout and dramatic diagonal perspective leaning clockwise toward the bottom-right, its top edge sloping upward toward the right as in the reference. Keep the soft light-gray studio background, gentle lighting and realistic metallic side buttons, glass and skin texture. Remove ALL app interface content from the screen: every text, date, Journey title, cards, plus button, icons, medication items, purple insight box. Replace the entire display surface with one completely uniform clean very light warm-gray blank screen, without UI or writing, while keeping the native black dynamic island near the top edge. No status-bar text or symbols either, since those will be added by code. Portrait 4:5 composition, leaving the upper 26% of the whole image mostly empty light-gray background for an external website title. The large tilted phone starts below that space, occupies most of the lower image, and extends beyond the bottom and right edges; fingers remain visible along the left and right device edges. Maintain a simple flat rectangular glass display in perspective with distinct visible screen boundaries and sharp top corners rounded by the device bezel. The blank display must be unobstructed so real HTML/CSS charts can be accurately projected onto it later. No floating panels outside the phone, no graphics, no text, no watermark. Do not create a new app interface.
